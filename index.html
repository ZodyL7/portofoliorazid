Maintenance & Hardware

Maintenance & Perawatan Laboratorium Komputer SMPN 1 Wagir

Proyek ini merupakan kegiatan Project Based Learning (PJBL) yang dikerjakan bersama Kelompok 8 kelas X TKJ A, dengan fokus pada maintenance dan perawatan laboratorium komputer di SMPN 1 Wagir.

Pekerjaan yang dilakukan meliputi troubleshooting perangkat, pemeriksaan koneksi jaringan, update sistem operasi, optimasi performa Windows, perbaikan driver suara, hingga pembersihan menyeluruh unit komputer.

Dari sekitar 24 komputer Dell All-in-One yang ditangani, seluruhnya berhasil diperbaiki dan dikembalikan ke kondisi siap pakai.

Networking & Server

Penyediaan Media Server Terpusat Menggunakan Jellyfin

Proyek pembelajaran ini bertujuan merancang dan menguji sebuah media server terpusat menggunakan Jellyfin yang berjalan di atas sistem operasiDebian.

Simulasi dan pengujian dilakukan menggunakan VirtualBox untuk meniru lingkungan server sebelum diterapkan pada perangkat sesungguhnya.

Tujuan dari proyek ini adalah memudahkan client mengakses media pembelajaran dari satu server terpusat, tanpa bergantung pada penyimpanan lokal di masing-masing perangkat.

Pembelajaran Sistem Komputer

Maket Pemrosesan Data pada Sistem Input Output

Maket ini dibuat sebagai media pembelajaran untuk menjelaskan secara visual bagaimana sebuah sistem komputer memproses data: mulai dari tahap input, pemrosesan, hingga menghasilkan output.

Melalui proyek ini, konsep dasar arsitektur sistem komputer menjadi lebih mudah dipahami secara nyata, tidak hanya secara teori.
